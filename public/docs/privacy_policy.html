2. Какие персональные данные мы собираем

2.1. В рамках функционирования сервиса Оператор может собирать и обрабатывать следующие данные Пользователя:

2.1.1. Фамилия, имя, отчество;

2.1.2. Контактный номер телефона;

2.1.3. Адрес электронной почты;

2.1.4. Адрес доставки готовых изделий;

2.1.5. Идентификатор пользователя в мессенджере Telegram (в случае использования Telegram-бота для авторизации или получения уведомлений о статусе заказа);

2.1.6. Технические данные, которые автоматически передаются устройством пользователя: IP-адрес, данные файлов cookie, информация о браузере, времени доступа и адресах запрашиваемых страниц.

3. Цели обработки персональных данных

3.1. Персональные данные собираются исключительно для следующих целей:

3.1.1. Идентификация Пользователя на сайте для оформления заказа;

3.1.2. Обработка и получение платежей;

3.1.3. Изготовление кастомного изделия по параметрам, заданным в 3D-редакторе;

3.1.4. Организация доставки физического товара по указанному адресу;

3.1.5. Направление служебных уведомлений, касающихся статуса заказа, в том числе через мессенджер (Telegram) или email;

3.1.6. Улучшение качества работы сайта и пользовательского интерфейса (аналитика).

4. Порядок сбора, хранения и передачи персональных данных

4.1. Безопасность персональных данных обеспечивается путем реализации правовых, организационных и технических мер, необходимых для выполнения требований действующего законодательства.

4.2. Оператор не передает персональные данные третьим лицам, за исключением случаев, связанных с исполнением заказа (например, передача адреса и телефона курьерской службе или транспортной компании).

4.3. Оплата заказов осуществляется через защищенное соединение платежного сервиса ЮKassa. Оператор не собирает, не хранит и не обрабатывает реквизиты банковских карт Пользователя — эта информация вводится непосредственно на стороне платежной системы.

4.4. Срок обработки и хранения персональных данных не ограничен, однако Пользователь может в любой момент отозвать свое согласие.
